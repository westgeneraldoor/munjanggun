# 문장군 디지털 쇼룸 v2 — Project Brief

## 비전
**"개발자 없이, 사장님이 직접 구성·운영하는 프리미엄 디지털 쇼룸"**

기존 컬러북의 성공을 기반으로, 하드코딩 구조를 범용 CMS로 전환하여
컬러 · 디자인 · 향후 어떤 탭이든 어드민에서 자유롭게 추가·관리할 수 있는 구조로 업그레이드.

## 문제 정의
1. **현재:** 컬러 파트만 존재 → 디자인(도어 형태) 정보를 보여줄 수 없음
2. **구조적 한계:** 하드코딩 구조라 새 카테고리(디자인, 인테리어 등) 추가 시마다 개발자 필요
3. **운영 비효율:** 메인 페이지, 탭 구성, 카드 레이아웃 변경에 코드 수정 필요

## 타겟 사용자
- **1차:** 문장군 영업사원 — 카톡 링크 하나로 고객에게 쇼룸 전달
- **2차:** 고객(건축주/인테리어업체) — 컬러와 디자인을 몰입감 있게 탐색
- **어드민:** 사장님(1인) — 모든 콘텐츠를 직접 구성·운영

## 핵심 가치 제안
**"한 번 만들면, 이후 모든 콘텐츠 운영은 어드민에서 끝"**

- 새 탭(디자인, 시공후기 등) → 코드 수정 없이 어드민에서 추가
- 이미지 업로드 → 기준 사이즈로 자동 압축
- 탭별 메인화면 on/off → 토글 하나로 노출 제어
- 모든 단계에서 카카오톡 공유 → 해당 단계의 썸네일·제목·설명이 정확히 표시

## 기존 대안 & 차별점

| 기존 (v1) | 전환 후 (v2) |
|-----------|-------------|
| 컬러 전용 하드코딩 | 범용 CMS 구조 |
| 탭 추가 = 개발 필요 | 탭 추가 = 어드민에서 직접 |
| 메인 페이지 고정 | 히어로 텍스트/이미지/영상 어드민 설정 |
| 컬러 상세만 OG 태그 | 모든 단계별 OG 태그 (카톡 공유 최적화) |
| 이미지 수동 리사이즈 | 업로드 시 자동 압축 |

## CMS 구조 설계

### 페이지 계층 (모든 탭 공통 템플릿)

```
메인 페이지
├── 히어로: 영어부제 / 히어로문구 / 보조문구 / 이미지 or 영상
│   └── 이미지 여러 장 → 자동 슬라이딩
│   └── 영상 → 자동재생 백그라운드
├── 탭 목록: [컬러] [디자인] [+추가 가능]
│
탭 페이지 (예: 컬러, 디자인)
├── 히어로: 탭 대표 이미지 / 제목 / 설명
├── 카드 그리드 (세로 배열, 컬러와 동일)
│   └── 카드: 이미지 + 제목 + 설명
│
카테고리 페이지 (예: 컬렉션, 중문유형)
├── 히어로: 카테고리 대표 이미지 / 제목 / 설명
├── 하위 카드 그리드
│
아이템 상세 페이지 (예: 컬러 상세, 디자인 상세)
├── 대표 이미지 (히어로)
├── 제목 / 설명
├── 시공사진 갤러리
```

### 핵심: 컬렉션(카테고리) 레이어는 선택적

```
컬러 탭:    컬렉션(4개) → 컬러 아이템
디자인 탭:
  ├── 3연동중문 → 컬렉션(베이직/클래식/모던/아트) → 디자인 아이템
  ├── 원슬라이딩 → 컬렉션(베이직/클래식/모던/아트) → 디자인 아이템
  └── 스윙중문 → (컬렉션 없음) → 바로 디자인 아이템
```

어드민에서 컬렉션을 만들지 않으면 → 자동으로 아이템 목록 직행.

### 카카오톡 공유 (OG 메타태그)

모든 페이지 단계마다 해당 단계의 이미지·제목·설명으로 OG 태그 자동 생성:
- 메인 → 쇼룸 대표 이미지
- 탭 → 탭 대표 이미지
- 카테고리 → 카테고리 대표 이미지  
- 아이템 상세 → 아이템 대표 이미지

## MVP 범위 (v2 초기 버전)

### ✅ 포함
- DB 범용 CMS 구조로 마이그레이션 (기존 컬러 데이터 보존)
- 메인 페이지 어드민 설정 (히어로 텍스트/이미지/영상)
- 탭 시스템 (추가/삭제/순서변경/on·off)
- 탭별 카드 그리드 (이미지 + 제목 + 설명)
- 선택적 카테고리(컬렉션) 레이어
- 아이템 상세 페이지 (대표이미지 + 제목/설명 + 갤러리)
- 이미지 업로드 시 자동 압축 (기준 사이즈)
- 모든 단계별 OG 메타태그 (카카오톡 공유 최적화)
- 어드민 페이지 전면 리팩토링 (컬러/디자인 통합 관리)
- 디자인 탭 신규 추가 (3연동/원슬라이딩/스윙)

### ❌ 제외 (기존 금기사항 유지)
- 결제/장바구니
- 고객 회원가입
- 댓글/리뷰
- 다국어
- 검색/필터
- 알림
- AR/VR

## 기술 제약
- 기존 기술 스택 유지: Next.js (App Router) + Supabase + Vercel
- CSS Variables 디자인 토큰 기반 (TailwindCSS 미사용)
- Pretendard Variable 폰트 + Lucide React 아이콘
- `any` 타입 금지, `100dvh` 사용, `logError()` 사용 등 기존 코딩 규칙 동일

## 리스크

| 리스크 | 대응 |
|--------|------|
| 기존 컬러 데이터 마이그레이션 실패 | 원본 이미지 파일 전량 보유, git 브랜치 작업으로 원복 가능 |
| 어드민 리팩토링 범위 과대 | 컬러 어드민 구조를 기반으로 CMS 어드민으로 확장 (신규 개발 아님) |
| 프론트엔드 기존 UX 퇴행 | 컬러 상세 페이지 등 기존 검증된 레이아웃은 그대로 유지 |

## 리서치 결과 요약
- 기존 v1 프로덕트가 영업 현장에서 성공적으로 활용 중 → 제품-시장 적합성 검증 완료
- CMS 전환은 신규 기능이 아닌 구조적 업그레이드 → 운영 효율 극대화
- 악마의 변호인 검증 3항목 모두 "문제 없음" 판정
