## ━━━ 빠진 것 (Mode C 핵심) ━━━

"있는 것의 결함"이 아니라 **"없는 것의 부재"**를 여기에 적는다.

### 🎨 UX/UI 관점에서 빠진 것

**1. 페이지 전환 애니메이션 (View Transitions API)**
→ 카드 클릭 시 이미지가 히어로로 확장되는 shared element transition이 없음. 현재는 클릭→백지→로딩→새페이지. "프리미엄 갤러리" 경험과 거리가 멀다.
→ 있어야 하는 이유: Apple, Porsche 등 럭셔리 브랜드 웹사이트의 핵심 차별점. 카드→상세 전환에서 이미지가 자연스럽게 확대되면 몰입감이 비약적으로 상승.

**2. 패럴랙스/시네마틱 스크롤 효과**
→ 갤러리·히어로에서 스크롤에 반응하는 깊이감 있는 움직임 전무. 현재는 "나타남(fade-in)" 하나뿐.
→ 있어야 하는 이유: 소재·텍스처를 보여주는 쇼룸에서 "깊이감 있는 몰입 스크롤"은 제품 가치를 체감시키는 핵심 장치.

**3. 커서/호버 인터랙션 (데스크탑)**
→ 카드 호버가 translateY(-4px) 하나. 마우스 추적 틸트, 이미지 줌, 글레어 효과 등 없음.
→ 있어야 하는 이유: 데스크탑에서 "만져보고 싶은" 소재감을 전달하려면 커서 인터랙션이 필수.

**4. 스켈레톤 로딩 / 프로그레시브 이미지**
→ 이미지 로딩 중 빈 공간 → 갑자기 나타남. 블러 프리뷰(LQIP) 또는 스켈레톤 없음.
→ 있어야 하는 이유: 카톡 인앱에서 3G/LTE 환경 고려 시, 로딩 체험이 프리미엄 인상에 직결.

**5. 상세 페이지 섹션 다양성**
→ 현재: 히어로→정보→갤러리 3단 고정. "이전/다음 네비게이션", "관련 제품", "시공 Before/After" 등 없음.
→ 있어야 하는 이유: 상세 페이지에서 체류시간을 늘리고 구매 전환을 높이는 컨텐츠 깊이.

**6. 폰트 드라마 (Playfair Display 미활용)**
→ 디자인 시스템에 "영문 Display: Playfair Display"로 선언했으나, 실제 고객 컴포넌트에서 `font-family: var(--font-display)` 사용처가 없음. layout.tsx에서 CSS 변수만 선언하고 끝.
→ 있어야 하는 이유: 세리프 + 산세리프 대비는 "절제된 고급감"의 핵심인데, 실제로 적용되지 않으면 디자인 시스템이 유명무실.

### 📊 사업 전략 관점에서 빠진 것

**7. "쇼룸다움"의 정의 부재**
→ 현재 프로젝트는 기술적으로 "노드 기반 CMS + 카드 그리드"인데, 이는 카페24·Wix·Squarespace와 구조적으로 동일. "쇼룸"이라는 이름에 걸맞은 **체험적 차별점**이 코드에 구현되어 있지 않음.

**8. 브랜드 스토리텔링 레이어**
→ 사장님이 "고급화"를 원한다면, 단순 제품 나열이 아닌 **브랜드 서사**를 전달하는 레이어가 필요. 현재는 히어로 문구 3줄이 전부.

## ━━━ 돌파 과제 ━━━

### 🏆 최우선: "카페24가 절대 못 하는 것" 3가지

**1. 시네마틱 페이지 전환 (View Transitions)**
→ 카드 이미지가 상세 히어로로 매끄럽게 확장. Next.js + View Transitions API.
→ 예상 효과: "이 사이트 뭐야?" 순간 와우 팩터. 카페24/스마트스토어에서 절대 불가능한 체험.
→ 난이도: 중. Next.js experimental viewTransition 활용.

**2. 인터랙티브 소재 뷰어**
→ 카드 호버 시 마우스 추적 3D 틸트 + 빛 반사 효과(글레어). 소재 텍스처를 "만지는 듯한" 느낌.
→ 예상 효과: "오프라인 컬러북을 넘어서는" 이라는 비전에 직결. 디지털에서만 가능한 체험.
→ 난이도: 중. CSS perspective + JS mousemove. Framer Motion 없이 가능.

**3. 시네마틱 스크롤 갤러리**
→ 갤러리를 단순 2컬럼 나열이 아닌, 스크롤에 따라 이미지가 깊이감 있게 등장하는 매거진 레이아웃.
→ 패럴랙스 + 스케일 애니메이션 + staggered reveal.
→ 예상 효과: 시공 사례 갤러리가 "포트폴리오 전시"처럼 느껴짐. 고객이 스크롤을 멈출 수 없게 만듦.
→ 난이도: 중. IntersectionObserver + CSS transforms. 현재 아키텍처로 충분히 가능.

### 🥈 차순위

**4. LQIP(블러 프리뷰) + 스켈레톤 로딩**
→ next/image의 `placeholder="blur"` + `blurDataURL` 활용.
→ 예상 효과: 카톡 인앱 저속 환경에서도 프리미엄 느낌 유지.

**5. Playfair Display 실제 적용**
→ 히어로 제목, 섹션 라벨, 카드 부제 등에 `font-family: var(--font-display)` 적용.
→ 예상 효과: 즉시 "고급 갤러리" 느낌 향상. 작업량 최소.
