# 플레이북: Phase 4 안전망 및 접근성 폴리싱
📅 발행: 2026-05-19
🤖 추천 모델: Gemini 1.5 Pro
⏱️ 예상 시간: ~30분

## 🎯 실행 목표
배포 직전 최종 안전망 구축. 네트워크 에러 대비, 이미지 로딩 실패 대비(Fallback), 그리고 시각장애인 및 키보드 네비게이션을 위한 접근성(A11y) 강화.

---

### Task 1. Global Error Boundary 추가 🟡
**목표:** 전체 앱에서 에러 발생 시 하얀 화면이 뜨지 않도록 범용 에러 UI 구현
- **파일:** `src/app/error.tsx` 생성
- **내용:** 
  - Next.js의 Error Boundary 구조 (`'use client'`, `reset` 함수 포함)
  - 빈 화면(Empty State) 디자인 시스템 재사용 (제목: "일시적인 오류가 발생했습니다", 내용: "페이지를 불러오는 중 문제가 발생했습니다.")
  - "다시 시도" 버튼 추가 (기존 버튼 스타일 토큰 사용 `var(--color-accent)`)

### Task 2. 접근성(A11y) 및 alt 속성 점검 🟡
**목표:** 모든 버튼과 이미지에 시각장애인용 대체 텍스트 확인
- **파일:** `src/components/customer/CTABar.tsx`, `ScrollToTop.tsx`, `NodeCard.tsx` 등
- **수정사항:**
  - 아이콘만 있는 버튼(홈 버튼, 위로가기 버튼 등)에 `aria-label` 속성 추가
  - `next/image`를 사용하는 곳에 빈 `alt=""`가 아닌 의미 있는 노드 이름이나 설명이 들어갔는지 점검 (이미 되어있다면 유지)

### Task 3. 이미지 로드 에러 Fallback (선택/확인) 🟢
**목표:** 서버 통신 장애로 이미지 로드가 깨졌을 때 엑스박스 방지
- **내용:** `next/image`에서 이미지가 깨졌을 경우를 대비한 최소한의 CSS 처리가 잘 되어 있는지 확인. (빈 회색 박스로 나오도록) 특별한 수정이 필요 없다면 넘어가도 무방함.
