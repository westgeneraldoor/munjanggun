# 문장군 블로그 출시 화면정의서

## `/blog`

역할: 문장군의 공개 지식 허브.

핵심 화면 블록:

1. 이미지 hero
   - 제목: 중문과 도어를 고르기 전, 집에서 먼저 확인할 이야기.
   - CTA: 궁금한 글 찾기, 무료방문 실측견적 안내
   - 이미지: 밝은 주거 공간 편집 이미지

2. 주제 입구
   - 전체 글
   - 중문과 도어 고르기
   - 현장에서 확인하는 것
   - 가격과 견적
   - 시공 사례
   - 고객 질문
   - 제작과 운영 이야기

3. 검색
   - 블로그 글 제목, 요약, 질문, 키워드, 지역, 제품군 기준 검색

4. 먼저 읽기 좋은 글
   - target question, summary answer가 있는 글 우선

5. 최근 올라온 글
   - 최신순 글 카드

6. 궁금한 단어로 이어보기
   - 고객 질문/키워드/지역/제품군 단어를 통한 탐색

7. 무료방문 실측견적 CTA
   - `/measure`로 이동

## `/blog/[slug]`

역할: AEO 답변형 상세 글.

현재 유지:

- 모바일 읽기 상단바
- 도움돼요
- 저장
- 질문하기
- 관련 글/이어 읽기

이번 작업에서 변경:

- 글 내부 CTA가 직접 폼으로만 가는 느낌을 줄이기 위해 기본 CTA를 `/measure`로 보정한다.
- `source=blog-question`이 붙는 질문 흐름은 기존처럼 `/portal/measure/new`를 유지한다.

## `/measure`

역할: 블로그 독자가 신청 폼 전에 보는 설득 랜딩.

화면 블록:

1. Hero
   - “집에 맞는지 먼저 보고, 결정은 그 다음에 하세요.”
   - CTA: 무료방문 실측견적 신청, 글 더 읽어보기
   - 이미지: 실측 도구와 현관/문틀 분위기 이미지

2. 이럴 때 신청하세요
   - 구조가 애매할 때
   - 신발장/스위치/단차가 걸릴 때
   - 인터넷 가격만으로 판단하기 어려울 때
   - 블로그를 읽고도 우리 집 조건이 남을 때

3. 진행 순서
   - 집 조건 확인
   - 가능한 방식 정리
   - 견적 범위 안내
   - 진행 여부 결정

4. 준비하면 좋은 것
   - 설치 위치 사진, 희망 제품, 연락 가능 시간

5. FAQ
   - 비용 발생 여부
   - 사진 준비 여부
   - 바로 신청 가능 여부

6. Final CTA
   - `/portal/measure/new`

## `/portal`

역할: 블로그 출시용 최소 마이페이지.

우선순위:

1. 저장한 글
2. 도움된 글
3. 내 질문
4. 무료방문 실측견적 연결
5. A/S 접수는 보조
6. 최근 상담/A/S 이력은 아래쪽 확인 영역

링크 규칙:

- 상단 홈 버튼: `/blog`
- 상단 문장군 로고: `/blog`
- 새 상담 신청: `/measure`
- 로그아웃 후 이동: `/blog`

## 공개 로그인 메뉴

로그인 전:

- 로그인 버튼

로그인 후 고객:

- 블로그 홈
- 마이페이지
- 무료방문견적 안내
- 로그아웃

관리자:

- 고객 메뉴 항목
- 플랫폼 어드민

표시명:

- DB 또는 auth metadata 이름이 깨진 값이면 `문장군 고객` 또는 `문장군 관리자`로 보정한다.
