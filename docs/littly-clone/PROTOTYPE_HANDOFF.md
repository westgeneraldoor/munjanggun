# 링크 페이지 프로토타입 인수 문서

작성일: 2026-08-14

## 실행 위치

- 편집기: `/link-pages`
- 공개 페이지: `/l/{slug}`
- 예시 공개 페이지: `/l/munjanggun`, `/l/sliding-door`

## 이번 구현에서 보장하는 것

- 편집기 미리보기와 공개 페이지가 동일한 `LinkPageRenderer`와 `BlockRenderer`를 사용한다.
- 프로필, 단일 링크, 그룹 링크, 텍스트, 갤러리, 동영상, 파일 공유의 승인된 7개 블록만 제공한다.
- 페이지와 블록 ID는 수정·정렬 때 유지되고 복사할 때만 새 ID를 발급한다.
- 블록은 손잡이 드래그와 접근 가능한 위·아래 버튼으로 정렬한다.
- 페이지 계층은 깊이 제한 없는 `parentId` 트리이며 순환 부모를 선택할 수 없다.
- 모든 페이지는 부모를 거치지 않고 `/l/{slug}`로 직접 진입할 수 있다.
- slug 변경 전 주소는 alias로 남아 새 평면 URL로 연결된다.
- 페이지 조회와 블록 클릭 이벤트를 기록한다.
- 이미지와 파일 원본은 IndexedDB, 구조화 상태와 이벤트는 localStorage에 저장한다.

## 화면 범위

- `페이지`: 실제 동작
- `디자인`: 배경색, 버튼색, 폰트 실제 동작
- `분석`: 탭과 범위 안내만 제공하며 이벤트 기록만 실제 동작
- `관리`, `마케팅`: 리틀리 셸의 메뉴 자리는 유지하되 이번 프로토타입에서는 안내 화면만 제공

## 프로토타입 경계

현재 저장소는 브라우저 로컬 저장소를 사용하는 안전한 클릭 프로토타입이다. 다른 기기·다른 브라우저와 자료를 공유하는 운영 버전은 같은 repository 경계를 Supabase 구현으로 교체한 뒤 배포한다. 파일 공유의 개인정보 수집 옵션은 동의·보관 정책이 확정될 때까지 비활성이다.
