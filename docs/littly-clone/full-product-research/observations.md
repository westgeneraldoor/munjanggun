# Verified observations

이 문서는 화면에서 직접 확인한 사실, 그 사실에서 도출한 구현 판단, 아직 남은 경계를 분리한다. 상세 파일 연결은 `manifest.json`, 블록별 연결은 `BLOCK_EVIDENCE.md`가 담당한다.

## 직접 확인한 사실

- 전역 정보구조는 `페이지 / 디자인 / 분석 / 관리 / 마케팅` 5개 고정 메뉴다.
- 편집기 셸은 좌측 페이지 레일, 중앙 모바일 미리보기, 우측 작업 패널의 3열 구조다.
- 페이지 추가는 `멀티 페이지`와 `서브 페이지` 두 유형을 제공한다.
- 공개 화면에서 `홈화면`을 누르면 `/munjanggun.com`, `페이지`를 누르면 `/munjanggun.com/page1`로 왕복한다. 따라서 리틀리는 실제 탐색 계층을 제공한다.
- 모든 공개 노드는 직접 URL로 진입할 수 있다. 홈과 자식 페이지는 각각 독립 URL을 가진다.
- 블록 선택기는 총 24종이며 콘텐츠 10, 커뮤니케이션 7, 수익화 6, 외부 연동 1로 묶인다.
- 24종 모두 편집 화면, 주요 유형·옵션·하위 모달을 Chrome에서 확인했다. 다만 공개 PC/모바일·오류·정렬까지 같은 기준으로 닫힌 것은 단일 링크·동영상·텍스트와 프로필이다.
- 프로필은 ON/OFF, 4개 레이아웃, 이미지, 대표문구, 상세문구, 3개 글자 크기를 제공한다.
- 디자인의 `추천 디자인 제작`은 확인 모달 없이 즉시 디자인을 변경하고 저장한다. 시험 후 원래 값으로 복원하고 새로고침 뒤 유지까지 확인했다.
- 분석 기간은 `전체기간 / 오늘 / 일주일 / 1개월 / 3개월 / 6개월 / 직접 입력`이며, 6개 `전체보기`는 현재 무료 플랜에서 같은 브랜드 플랜 잠금 모달을 연다.
- 관리에는 고객정보, 매출현황, 광고수익 상세 화면이 있다.
- 마케팅에는 단체 이메일, 수신자 선택, 인스타 DM 자동화, 인스타 계정 연결 진입, 준비중인 문자 기능이 있다.
- 공개 공유 모달은 URL 복사, QR, PNG 저장, SVG 저장, 무료개설, 페이지 신고를 제공한다.
- 공개 구독 모달은 이메일, 구독 버튼, 개인정보·광고성 정보 수신 동의를 제공한다.
- 공개 데스크톱과 390×844 모바일을 저장했다. 최신 보완 조사에는 동영상·텍스트의 공개 PC/모바일가 각각 포함된다.
- 페이지명과 slug를 실제로 변경해 새 공개 URL 반영을 확인하고 `페이지/page1`로 원상복구했다. 이전 slug는 404가 아니라 홈 공개 페이지로 fallback했다.
- 갤러리와 파일공유의 file chooser는 Chrome 확장 권한 때문에 `code -32000 / Not allowed`로 거부됐다. 그룹 링크는 이미지가 필수라 같은 권한에 막혔다.

## 구현 판단

- 리틀리의 공개 페이지 렌더러와 편집기 미리보기는 같은 블록 스키마를 공유하는 구조로 구현해야 한다. 화면을 별도 구현하면 옵션 조합이 어긋날 위험이 크다.
- 페이지 URL은 계층 경로와 분리한 고정 slug를 사용하고, 부모·자식 관계는 별도 데이터로 보존하는 편이 현재 확정 사양과 맞는다.
- 탐색 계층은 별도 발명 항목이 아니라 리틀리의 서브 페이지와 공개 탭 왕복을 90 기준으로 삼을 수 있다.
- 수익화·관리·마케팅은 초기 영업 자료 허브의 핵심 동선과 분리한다. 1차 프로토타입은 상단 메뉴 자리만 유지하고 실제 기능은 만들지 않는다. 조사한 화면은 후속 범위 판단의 참고 근거로 보존한다.

## 확인 경계

- 실제 페이지 복사·삭제, 이메일·DM 발송, 인스타 계정 연결, 수익계좌, 결제는 외부 효과 또는 플랜 제한 때문에 실행하지 않았다.
- 사용자 파일 업로드는 합성 이미지/PDF로 시도했으나 Chrome 확장 로컬 파일 권한에서 차단됐다. 실제 사용자 파일은 사용하지 않았다.
- 디자인의 모든 아이콘 조합과 유료 잠금 조합 전체를 순열로 실행하지는 않았다.
- 위 경계는 화면·스키마·주요 사용자 흐름을 구현하는 데 장애가 되지 않지만, 해당 고급 기능을 실제 출시 범위에 넣을 때는 별도 검증이 필요하다.

## 증거 무결성

- 1차 `manifest.json`: 유효 화면 106개, DOM/원문 153개, 측정 40개의 역사적 경로·크기·SHA-256.
- `completion-pass/manifest.json`: 최신 보완 화면 59개, DOM/원문 56개, 측정 2개의 경로·크기·SHA-256.
- `completion-pass/validation.json`: 신규 JPEG 59개 매직바이트·실제 크기, JSON 파싱, 빈 원문 검증 통과.
- 현재 조사 원본 637개는 저장소 밖 비공개 폴더에 같은 상대 경로로 보존했다. 공통 637개의 SHA-256 비교 결과 누락 0건·불일치 0건이다. 비공개 폴더에는 PDF 확인용 렌더 1개가 추가로 있어 총 638개다.
- Chrome이 JPEG 바이트를 `.png` 이름으로 반환한 파일은 실제 포맷에 맞춰 `.jpg`로 교정했고 `image-extension-renames.json`에 전부 기록했다. 그중 지연 프레임 3개는 최종 증거에서 제거해 유효 JPEG는 105개다.
- 실제 PNG인 사용자 원본 1개는 변경하지 않았다.
