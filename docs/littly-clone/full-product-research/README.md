# Littly full-product research v2

이 디렉터리는 리틀리 전체 제품을 상위 정보구조부터 다시 조사하는 새 권위 저장소다.

이전 `direct-research/`와 `evidence/`는 역사적 참고자료이며, 현재 완료 판정의 대체 증거로 사용하지 않는다. 2026-08-14 보완 증거는 `completion-pass/`에 있다.

## 완료 범위

1. 공통 편집기 셸
2. 페이지
3. 디자인
4. 분석
5. 관리
6. 마케팅
7. 페이지 관리 생명주기와 공통 도구
8. 실제 블록 24종
9. 공개 데스크톱과 390px 모바일
10. 시각 토큰, 상태, 모달, 저장, 원상복구

## 증거 단위

각 조사 항목은 다음을 가능한 범위에서 함께 보존한다.

- 전체 화면 캡처 또는 캡처 실패 원문
- DOM·접근성 트리
- 주요 요소의 위치·크기·색·폰트·간격·반경
- 수행한 조작과 반영 대기
- 공개 결과
- 안전상 미실행한 외부 효과
- 삭제와 새 세션 재접속 원상복구

## 판정

- `VERIFIED`: 해당 행의 필수 상태 증거를 모두 충족
- `PARTIAL`: 필수 상태 중 하나 이상이 누락
- `UNKNOWN`: 확인 근거 없음
- `BLOCKED`: 도구·플랜·외부 상태 때문에 현재 검증 불가
- `N/A`: 해당 동작이 적용되지 않음

`INTENTIONAL`은 조사 상태가 아니라 문장군 제품 결정으로 별도 기록한다.

## 읽는 순서

1. `observations.md` — 직접 확인한 사실, 구현 판단, 확인 경계.
2. `FULL_PRODUCT_MAP.md` — 5개 전역 메뉴와 공개 페이지의 전체 제품 지도.
3. `BLOCK_EVIDENCE.md` — 24개 블록별 이미지·DOM·정리 증거 원장.
4. `COVERAGE.md` — 영역별 최종 판정과 의도적으로 실행하지 않은 외부 효과.
5. `IMPLEMENTATION_SCOPE.md` — 대표 확인 전 실제 동작 프로토타입의 포함·제외 범위.
6. `completion-pass/manifest.json` / `completion-pass/validation.json` — 최신 보완 증거의 해시와 형식·크기·파싱 검증.
7. 루트 `manifest.json` / `validation.json` — 1차 full-product 조사 묶음의 역사적 무결성 기록.

현재 연구 묶음은 `RESEARCH_COMPLETE`이며 공통 셸과 1차 실제 동작 프로토타입의 구현 입력으로 사용할 수 있다. 그룹 링크·갤러리·파일공유의 실제 업로드 후 상태는 증거상 `PARTIAL`, 제작 게이트상 `NON_BLOCKING_UNVERIFIED`다. 이 항목을 이유로 업로드 권한 조사를 재개하지 않는다. 실제 발송·결제·계정연동처럼 외부 효과가 있는 기능은 이번 제작 범위가 아니며, 별도 승인과 보안 검증 없이는 실행하지 않는다.
