# Actual prototype scope

이 문서는 조사 범위와 현재 제작 범위를 분리한다. 현재 단계는 본 배포가 아니라 대표가 직접 눌러 확인할 실제 동작 프로토타입이다. 이 결과를 확인하기 전에는 전체 블록이나 전역 메뉴 기능으로 범위를 확대하지 않는다.

## 전역 메뉴 범위

| 메뉴 | 프로토타입 셸 | 실제 동작 | 이번에 만들지 않음 |
|---|---|---|---|
| 페이지 | 3열 편집기, 페이지 레일, 프로필, 블록 카드·선택기, 실시간 미리보기 | 페이지 CRUD, 고정 slug, `parent_id/sort_order`, 독립 진입 URL, 7개 블록 편집·정렬·공개 렌더 | 나머지 17개 블록 |
| 디자인 | 리틀리 제어 배치와 선택 상태 | 배경색·버튼색·폰트 | 사진 배경·커스텀 로고·고급 조합 |
| 분석 | 상단 탭 자리와 비대상 안내 | 화면 없이 페이지 조회·블록 클릭 이벤트 기록 | KPI·차트·순위·기간·다운로드 대시보드 |
| 관리 | 상단 탭 자리와 비대상 안내 | 없음 | 고객정보·CRM·주문·매출·정산·광고·계좌 |
| 마케팅 | 상단 탭 자리와 비대상 안내 | 없음 | 이메일·DM·문자 발송과 외부 계정 연결 |

## 블록 범위

| 포함하는 7개 | 공통 동작 |
|---|---|
| 프로필, 단일링크, 그룹링크, 텍스트, 갤러리, 동영상, 파일공유 | ON/OFF, 정렬, 복사, 삭제 확인, 같은 렌더러의 편집 미리보기와 공개 페이지 |

SNS, 여백, 음악, 지도, 문의, 일정, 고객정보, 연락처, 공지, 검색, 방명록, 국내·해외 판매, 후원, 예약, 광고, 멤버십, 스마트스토어는 조사 근거만 보존하고 이 프로토타입에서는 구현하지 않는다.

## 확정 구조

- 공개 URL은 계층과 분리한 평면 slug를 사용한다. 예: `/l/{slug}`.
- 데이터 모델은 `parent_id`와 `sort_order`로 탐색 계층을 지원한다.
- 모든 노드는 부모를 거치지 않고 독립 URL로 완전히 열려야 한다.
- 편집기 미리보기와 공개 페이지는 같은 블록 렌더러를 사용한다.
- 리틀리의 코드·브랜드·문구·그래픽 자산은 가져오지 않고 화면 구조와 조작 흐름을 독립 구현한다.

## 착공 경계

공통 셸과 위 7개 블록의 실제 동작 프로토타입은 현재 자료로 시작할 수 있다. 그룹 링크·갤러리·파일공유의 리틀리 업로드 후 상태는 `NON_BLOCKING_UNVERIFIED`이며 권한 해소를 기다리지 않는다. 우리 저장소와 업로더로 먼저 구현하고, 필요할 때만 완성된 구현물과 리틀리를 대조해 보정한다.

실제 발송·결제·계좌·외부 계정 연결은 별도 승인 없이는 구현·시험하지 않는다. 이 프로토타입을 대표가 직접 확인한 뒤에만 본 제작 스펙과 후속 범위를 확정한다.
