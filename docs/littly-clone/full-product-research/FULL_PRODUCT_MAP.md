# Littly full product map — live research

이 문서는 이전의 블록 중심 완료 판정을 대체하는 신규 권위 지도다. 아직 완료 문서가 아니며, 각 항목은 `COVERAGE.md`와 원시 증거가 함께 있어야 확정된다.

## 공통 셸

- 좌측: 설정, 페이지 추가, 홈화면 카드, 일반 페이지 카드, 추가 슬롯.
- 중앙: 실제 공개 페이지와 동일 계열의 모바일 미리보기, 상단 공유/알림, 하단 공개 URL/복사/공유 도구.
- 우측 상단: `페이지 / 디자인 / 분석 / 관리 / 마케팅` 5개 고정 메뉴.
- 우측 본문: 선택 메뉴의 편집 또는 업무 패널. 기본 폭 550px.
- 1300px 인앱 기준 상단 메뉴는 각 108×54px, 활성 메뉴는 검정 배경의 disabled 버튼 상태다.

## 1. 페이지 (`/page`)

- 프로필 아코디언.
- 현재 블록 카드: 단일 링크 2개, 스마트스토어 연동 1개.
- 블록마다 펼침/접힘과 중간 삽입용 원형 `+` 버튼이 반복된다.
- 하단 `+블럭 추가`: 550×54px, 검정, 반경 10px.
- 페이지 추가는 `멀티 페이지`와 `서브 페이지` 두 유형을 제공한다.
  - 멀티 페이지: 독립 링크를 가진 복수 페이지 관리. `/pagelist` 목록 화면으로 이동한다.
  - 서브 페이지: 현재 페이지의 하위 페이지를 만드는 탐색 계층 기능. 현재 계정에서는 브랜드 플랜 잠금 모달이 열린다.
- 페이지 카드 더보기: `편집 / 복사 / 삭제`.
- 편집 모달: 페이지 이름과 `litt.ly/munjanggun.com/{slug}` 주소를 수정하고 `설정 완료`로 저장한다.
- 블록 선택기는 총 24종이다: 콘텐츠 10, 커뮤니케이션 7, 수익화 6, 외부연동 1.
- 프로필 세부, 공통 공유/알림, 나머지 블록 23종의 편집 폼과 주요 하위 모달까지 조사했다. 전체 공개 렌더러 완료 여부는 `COVERAGE.md`가 판정한다.

## 2. 디자인 (`/design`)

- `추천 디자인 제작`.
- 배경색: 프리셋/색상값/사진 업로드.
- 버튼색: 다수 프리셋/색상값, 부분 적용·전체 적용.
- 버튼 모양 3종.
- 버튼 액션 5종.
- 폰트 8개 기본 선택지 + 추가 폰트 콤보박스.
- 상단메뉴 표시 유형.
- 공유/구독 버튼: 노출/비공개와 공유/구독 선택.
- 로고: 기본 로고/내 로고/로고 삭제.
- `추천 디자인 제작`은 모달이 아니라 즉시 무작위 디자인을 적용하고 저장한다. 조사 중 변경된 배경/적용범위/폰트를 기존 값으로 되돌렸고 새로고침 뒤 복원 상태까지 검증했다.
- 대표 배경색·버튼색·버튼 모양·버튼 액션·폰트·상단 메뉴의 선택 전후 미리보기와 원상복구를 보완했다. 공유/구독과 커스텀 로고는 브랜드 플랜 잠금이다.

## 3. 분석 (`/report`)

- 기간 콤보박스 기본값 `일주일`.
- 다운로드는 현재 플랜에서 잠김, 업그레이드 진입 존재.
- KPI: 페이지 뷰, 클릭 수, 클릭율.
- 시계열: 클릭수/조회수 전환과 전체보기.
- BEST 클릭 순위와 전체보기.
- 유입 채널, 국가(세계지도+표), 도시, 기기 각각 요약과 전체보기.
- 하단 블록 분석: 검색, 클릭순 정렬, 블록별 클릭 횟수.
- 6개 `전체보기`는 무료 플랜에서 모두 동일한 브랜드 플랜 잠금 모달을 연다.
- 기간 옵션은 `전체기간 / 오늘 / 일주일 / 1개월 / 3개월 / 6개월 / 직접 입력` 7종이다.

## 페이지 설정

- 페이지 주소, 커스텀 도메인, 파비콘, SNS 공유 데이터, 구독정보, 공개 여부, QR코드, 글로벌 언어, 마케팅 연동, SEO/GEO, 링크 열기 방식, TikTok 외부 브라우저 안내 설정으로 구성된다.
- 무료 상태에서 상세 확보한 아코디언:
  - 구독정보: 이메일 수집 선택, 휴대폰 수집 선택.
  - 공개 여부: 전체 공개, 비밀번호 공개.
  - QR코드: PNG 저장, SVG 저장.
  - 링크 동작: 현재 탭, 새 탭.
  - TikTok 외부 브라우저: 안내 팝업 노출 스위치와 설명.

## 블록 신규 권위 조사

- `B01 단일 링크`: ON/OFF, 강조, 예약, 필수 연결 URL, 이미지, 필수 대표문구, 소/중/대 레이아웃, 강조 태그, AI 생성, 판매가, 정상가, 복사/페이지 이동/삭제 메뉴를 확인했다.
- 테스트용 블록을 삭제하고 같은 테스트 페이지에 단일 링크가 남지 않은 DOM 증거까지 저장했다.
- 나머지 23종은 편집 폼·주요 옵션·하위 모달·삭제까지 적용했다. 동일한 공개 PC/모바일·오류·정렬 상태 체인이 모두 있는 것은 아니며, 유형별 판정은 `BLOCK_EVIDENCE.md`에 있다.

## 공개 페이지와 탐색 계층

- 공개 데스크톱은 가운데 500px 계열 페이지 캔버스를 두고 바깥 배경을 채우는 구조다.
- 390px 모바일에서는 바깥 여백과 데스크톱 캔버스 프레임이 제거되고 콘텐츠가 화면 폭에 맞춰 확장된다.
- 공개 상단에는 공유와 구독 아이콘, 프로필, `홈화면 / 페이지` 탐색 탭이 있다.
- `홈화면`은 `https://litt.ly/munjanggun.com`, 자식 `페이지`는 `https://litt.ly/munjanggun.com/page1`로 이동하며 다시 홈으로 복귀할 수 있다.
- 공개 공유 모달은 URL 복사, QR, PNG/SVG 저장, 무료개설, 신고를 제공한다.
- 구독 모달은 이메일 입력, 동의, 구독 버튼으로 구성된다.

## 권위 증거 집계

- 유효 화면 106개: JPEG 105개, 사용자 원본 PNG 1개. 감사 과정의 지연 프레임 3개는 제거했다.
- DOM·원문 153개.
- 치수·구조화 측정 40개.
- `manifest.json`에 SHA-256과 바이트 크기, `validation.json`에 매직바이트·실제 이미지 크기·JSON/빈 파일 검증을 기록했다.
- 최신 `completion-pass/`에는 Chrome 보완 화면 59개, DOM/원문 56개, 측정 2개와 별도 manifest/validation이 있다.

## 4. 관리 (`/manage`)

### 고객 정보 (`/manage/collection` 모달)

- 요약 분류: 문의, 일정, 파일공유, 고객정보, 구독.
- 상세: 전체/문의/일정/파일공유/고객정보/구독 탭, 기간, 다운로드, 구글 시트 연동, 검색, 데이터 표.
- 무료 플랜에서 기간/다운로드/구글 시트가 잠긴 상태와 업그레이드 CTA가 함께 노출된다.

### 매출 현황

- 요약 분류: 판매, 후원, 예약, 멤버십.
- 상세: 계좌 연결, 기간, 다운로드, 구글 시트, 검색, 총 수익금/정산액, 주문 표.

### 광고 수익

- 계좌 연결, 기간, 다운로드, 구글 시트, 검색, 총 수익금/정산액, 광고 정산 표.

## 5. 마케팅 (`/marketing`)

- 단체 이메일 발송: 잔여 발송량, 메일 이력 표, 새 메일 작성.
- 새 메일 작성 첫 단계: 받는 사람 선택. 전체/문의/일정/파일공유/고객정보/구독/판매/후원/예약/멤버십, 마케팅 수신동의 필터, 기간, 검색, 고객 표.
- 인스타 DM 자동 발송: 자동화 목록 모달, 무료 자동화 만들기, Q&A.
- 새 자동화 첫 단계: 인스타그램 계정 연동. 실제 계정 연동은 실행하지 않음.
- 단체 문자 발송: 준비중 disabled 상태.

## 증거 규칙

- `screenshots/`: 실제 화면 이미지. 사용자 제공 이미지는 `USER-*`로 원본 보존.
- `raw/`: 화면 전체 접근성/DOM 스냅샷과 대화상자 상태.
- `measurements/`: 좌표, 크기, 색, 폰트, disabled 상태의 계산값.
- 이 문서의 항목이 확정되려면 적어도 DOM 또는 이미지 1개와 측정값 또는 상호작용 결과 1개가 필요하다.
