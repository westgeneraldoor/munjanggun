# Littly direct research authority

This directory contains observations made directly by the primary Codex
session after the multi-session investigation was stopped. Research is now
complete within the stated safety boundaries.

## Evidence rule

- Every claim is linked to a stable observation ID.
- UI state is preserved as DOM/accessibility/geometry evidence. Direct CDP
  screenshot attempts timed out and their errors are retained.
- Browser action time and reflection wait are recorded.
- Risky external effects (payment, message send, account connection, real
  booking, or customer-data submission) are inspected but not executed.
- Test blocks created on `page1` are removed after their investigation and the
  public desktop/mobile empty state is verified.
